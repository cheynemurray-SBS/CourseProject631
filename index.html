Required libraries

import pandas as pd
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt
import seaborn as sns

1. Data import and cleaning

# Load data
data = pd.read_csv('your_data.csv')

# Display basic info
print(data.head())
print(data.describe())
print(data.info())

2. Descriptive statistics

# Calculate key statistics
mean_value = data['your_variable'].mean()
std_value = data['your_variable'].std()
n = len(data['your_variable'])

print(f"Sample Mean: {mean_value}")
print(f"Sample SD: {std_value}")
print(f"Sample Size: {n}")

3. Check assumptions

# Normality test
from scipy.stats import shapiro
stat, p_value = shapiro(data['your_variable'])
print(f"Shapiro-Wilk test: p-value = {p_value}")

# Q-Q plot
from scipy.stats import probplot
probplot(data['your_variable'], dist="norm", plot=plt)
plt.title("Q-Q Plot")
plt.show()

4. Confidence interval

confidence_level = 0.95
degrees_freedom = n - 1
t_critical = stats.t.ppf((1 + confidence_level) / 2, degrees_freedom)

standard_error = std_value / np.sqrt(n)
margin_error = t_critical * standard_error

ci_lower = mean_value - margin_error
ci_upper = mean_value + margin_error

print(f"95% Confidence Interval: ({ci_lower:.2f}, {ci_upper:.2f})")

5. One-sample t-test

# Define hypothesized population mean
target_value = 7.5  # example

# Perform one-sample t-test
t_statistic, p_value = stats.ttest_1samp(data['your_variable'], target_value)

print(f"t-statistic: {t_statistic:.3f}")
print(f"p-value: {p_value:.3f}")

# Decision
alpha = 0.05
if p_value < alpha:
    print("Reject null hypothesis")
else:
    print("Fail to reject null hypothesis")

6. Visualizations

# Histogram with confidence interval
plt.figure(figsize=(10, 6))
plt.hist(data['your_variable'], bins=20, edgecolor='black', alpha=0.7)
plt.axvline(mean_value, color='red', linestyle='--', label=f'Mean: {mean_value:.2f}')
plt.axvline(ci_lower, color='green', linestyle='--', label='95% CI')
plt.axvline(ci_upper, color='green', linestyle='--')
plt.axvline(target_value, color='blue', linestyle='-', label=f'Target: {target_value}')
plt.xlabel('Your Variable')
plt.ylabel('Frequency')
plt.title('Distribution of Your Variable with CI')
plt.legend()
plt.show()

# Box plot
plt.figure(figsize=(8, 6))
plt.boxplot(data['your_variable'])
plt.ylabel('Your Variable')
plt.title('Box Plot of Your Variable')
plt.show()

# Confidence interval visualization
fig, ax = plt.subplots(figsize=(10, 6))
ax.errorbar(x=['Sample'], y=[mean_value],
            yerr=[[mean_value - ci_lower], [ci_upper - mean_value]],
            fmt='o', markersize=10, capsize=10, capthick=2, label='95% CI')
ax.axhline(y=target_value, color='r', linestyle='--', label=f'Target: {target_value}')
ax.set_ylabel('Your Variable')
ax.set_title('Sample Mean with 95% Confidence Interval')
ax.legend()
plt.show()

Common mistakes to avoid

Instead of“The p-value is 0.03.”
Write“The p-value of 0.03 suggests strong evidence against the null hypothesis, indicating satisfaction likely differs from target.”
Confusing statistical and practical significanceA p-value below 0.05 doesn’t mean the difference matters in business terms.
Ignoring assumptionsCheck normality, independence, and sample size, and discuss what happens if they’re violated.
Results without contextAlways connect statistical findings back to the business problem.
Jargon without explanationYour audience may not know what “null hypothesis” or “p-value” means.
Causal claims from observational dataYou can show association; proving causation requires an experimental design.
Skipping limitationsEvery analysis has limitations. Acknowledge them.
Code that doesn’t runRestart and run all before you submit.

Frequently asked questions

What if my p-value isn’t significant?

That’s fine. Not every analysis produces a significant result. Focus on proper interpretation and business implications.

How do I know if my problem is good enough?

Ask yourself: does someone care about the answer, can it inform a decision, and is there uncertainty to quantify? If the answer to all three is yes, it’s good.

Can I use a dataset we analyzed in class?

No. You must use different data to demonstrate independent learning.

What if I can’t meet the normality assumption?

Discuss it in your limitations section. With n ≥ 30, the t-test is fairly robust to violations. You can also consider data transformations or non-parametric alternatives.

How much Python code is enough?

Data loading, descriptive statistics, assumption checks, the confidence interval, the hypothesis test, and at least 2 or 3 visualizations.

Can I exceed 12 pages?

Try to stay within 8 to 12 pages for the main report. Put additional details in the appendices.

Can I make up data?

Only if you can’t get real data because of time constraints, and only with the instructor’s permission. Ask before you start.
